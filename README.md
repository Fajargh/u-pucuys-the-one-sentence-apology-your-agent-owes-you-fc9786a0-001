The one-sentence apology an AI assistant owes the person it works for: a single sentence, funny and human at once, owning a real failure instead of hiding behind a support macro.

## Run it

```sh
python3 main.py
```

The program writes the apology to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
